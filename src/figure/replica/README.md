# Reference replica (2026-10-11)

Faceted low-poly copy of the reference figure Gabriel sent (white low-poly man on a square plinth), published at
https://claude.ai/artifact/EosioMspbWPt4SdAXUCguU. replica_vs_reference.png shows it beside the reference from the matched camera.

- refgen.py [grid cm] [json overrides]: SDF sculpt measured from the reference image (cm, floor y=0, front +z, height 174);
  writes refbody.bin and refhead.bin. Overrides: head, hx, hz, hyaw, htilt, waist, hip, chest, armOut, leg, neck.
- pack2.mjs [bodyTris=720] [headTris=72]: meshoptimizer decimation of each part plus a six-sided neck -> refmesh.js (window.REFMESH {p,i}).
- replica_page.html: viewer; build by replacing /*MESH*/ with refmesh.js.
Matched camera: yaw -33 deg, fov 19, distance 710, target y 83.3, elevation 4 deg, plinth 72 x 11 cm.

Not on the site skeleton yet: it has its own proportions (arms hang, asymmetric stance, fists).
Note: three r160 ignores scene.environmentIntensity, so the RoomEnvironment fill always runs at full strength.


## v2 (2026-10-11): refit to Gabriel's five reference photos
- Widths come from the straight front/back photos; depths, offsets and cameras are fitted by outline overlap against all five (front ¾, side, back ¾, front, back). Overlap: 0.84 / 0.85 / 0.70 / 0.92 / 0.90.
- Rebuild: `python3 refgen.py 0.7 "$(cat final_params.json)" && node pack2.mjs 900 90 refmesh.js '{"rings":[],"mirror":false}' && python3 build_page.py`
- Keep the SDF cut planes off the marching-cubes grid (e.g. 152.63, not 152.6) or meshoptimizer collapses the head into a spike.
- Headless Chromium (SwiftShader) blows out RoomEnvironment lighting, so the page now uses hemisphere + key + rim lights only.
- The facet layout is generated by decimation, so it does not reproduce the reference's exact planes.


## v4 (2026-10-11): Gabriel's image-to-3D model is now the figure
- Gabriel generated a model from his photos (GLB, 50k tris, textured; Blender glTF export, node rotated +90 deg about X). He judged it far better than the traced and fitted attempts.
- generated/readglb.py reads the GLB geometry only (decoding the 20 MB texture ran out of memory in trimesh). Convert: y_up = -z, depth = y, scaled to 174 cm, centred on x. Front is +z already.
- generated/dec.mjs welds the UV seams and simplifies with meshoptimizer; 1,500 tris keeps every visible facet (error 0.0013). Result: generated/genmesh_1500.js.
- Outline overlap with the five photos: 0.86 / 0.83 / 0.88 / 0.94 / 0.92 (cameras in generated/cam_fit.json).
- traced_attempt/ holds the photo-facet-tracing pipeline (segment photo facets -> label the fitted body -> one plane per facet). It was superseded by the generated model.
