Privacy

This site records how visitors move through it, so I can see which parts people read, where they stop, and where the page is slow on their device. Nothing is sold or shared, there are no ads, and no other company's trackers run here. Back to the site

What a visit records

  • Where you scroll, where the camera points, where the pointer or finger is, what you click, and the arrow or WASD keys while you drive a build. Nothing you type anywhere else.
  • Your device as the browser reports it: type, model where offered, operating system, browser, screen and window size, CPU cores, memory, graphics chip, connection type, time zone, languages, and dark-mode and reduced-motion settings.
  • How the page ran: frame rate, freezes, 3D crashes and load time.
  • From the connection, as Cloudflare sees it: your IP address, network provider, and approximate location (country, region and city).

Returning visits

If you agree, or outside the EU, EEA, UK and Switzerland where the page doesn't need to ask, your browser keeps a random id (in local storage, not a cookie) for 13 months, so a second visit shows up as the same visitor. It identifies the device, not you, and it is never renewed. If you say no, or let the question fade, the page remembers that answer for the same time and doesn't ask again.

Where it goes and for how long

Visits are stored in this site's own storage at Cloudflare, which hosts it, and only I can see them. Each visit is kept for 90 days, then deleted by a daily cleanup.
